# Add your project screenshots

1. Copy your images from Downloads into this folder. Use simple filenames such as `before-i-deploy.png`.
2. Open `app/page.tsx`. In the matching project, change `image: ''` to `image: '/projects/before-i-deploy.png'`.
3. Save and refresh the local preview. Rebuild and redeploy to update the hosted site.

Repeat for all six projects. PNG, JPG, and WebP work well. A 16:10 image is ideal, but other sizes fit without cropping. Empty image values show a neutral placeholder.
